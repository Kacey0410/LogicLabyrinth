TODAY, I WOULD LIKE TO PRESENT OUR GAME PROJECT ENTITLED "LOGIC LABYRINTH."

THIS PROJECT IS A DUNGEON-STYLE RPG GAME CREATED USING PYTHON, TKINTER, AND SWI-PROLOG. THE GAME IS DESIGNED TO SHOW HOW PROGRAMMING CONCEPTS SUCH AS USER INTERFACES, GAME LOOP LOGIC, DATA STORAGE, AND ENEMY SYSTEMS CAN BE COMBINED INTO ONE FUNCTIONAL APPLICATION.

THE MAIN GOAL OF OUR GAME IS FOR THE PLAYER TO MOVE THROUGH DIFFERENT ROOMS, FIGHT ENEMIES, COLLECT ITEMS, LEARN PASSIVE SKILLS, AND EVENTUALLY DEFEAT THE FINAL BOSS. THE GAME IS BUILT IN A TURN-BASED FORMAT, SO THE PLAYER AND ENEMY TAKE TURNS IN ATTACKING AND DEFENDING.

WE USED PYTHON TO HANDLE THE MAIN GAME LOGIC AND INTERFACE. TKINTER WAS USED TO BUILD THE WINDOW, BUTTONS, STATUS BARS, MAP PANEL, AND BATTLE LOG. THE GAME WINDOW IS SIMPLE BUT FUNCTIONAL, WITH A CLEAR DISPLAY OF PLAYER AND ENEMY HEALTH, OUTLINED LABELS, ITEM INVENTORY, AND ROOM NAVIGATION.

THE MOST UNIQUE PART OF THE PROJECT IS THE USE OF SWI-PROLOG. THE PROLOG FILE CONTAINS THE GAME DATA, INCLUDING ITEMS, ENEMIES, BOSSES, SKILLS, SHRINE BUFFS, AND ROOM TYPES. THIS MAKES THE PROJECT MORE ORGANIZED AND DATA-DRIVEN BECAUSE THE GAME DOES NOT HARD-CODE EVERYTHING DIRECTLY IN THE PYTHON FILE.

IN THE GAME, THE PLAYER STARTS WITH BASIC STATS LIKE HP, ATTACK, AND DEFENSE. AS THEY EXPLORE THE DUNGEON, THEY CAN ENTER DIFFERENT ROOM TYPES. SOME ROOMS ARE COMBAT ROOMS, WHERE THEY FIGHT ENEMIES. SOME ARE LOOT ROOMS, WHERE THEY FIND ITEMS. SOME ARE SHRINE ROOMS, WHICH GRANT STAT BOOSTS. REST ROOMS ALLOW RECOVERY, AND SKILL ROOMS LET THEM CHOOSE PASSIVE ABILITIES THAT IMPROVE THEIR CHARACTER OVER TIME.

THE MAP IS ONE OF THE MAIN FEATURES OF THE GAME. IT DISPLAYS ALL AVAILABLE ROOMS, AND THE PLAYER CAN CLICK THEM TO NAVIGATE THE DUNGEON. AFTER A ROOM IS CLEARED, IT IS MARKED AS COMPLETED, AND THE PLAYER CAN CONTINUE EXPLORING THE FLOOR. ONCE ALL ROOMS ARE CLEARED, THE BOSS ROOM BECOMES AVAILABLE.

THE BATTLE SYSTEM IS ALSO ONE OF THE CORE ASPECTS OF THE GAME. DURING COMBAT, THE PLAYER CAN ATTACK, USE AN ITEM, OR FLEE. THE PLAYER'S ATTACK DAMAGE IS DETERMINED BY THEIR STATS AND SKILLS, WHILE THE ENEMY ATTACKS BACK ON ITS TURN. THE GAME ALSO TRACKS ENEMY HP, PLAYER HP, PASSIVE ABILITIES, AND SPECIAL BOSS EFFECTS.

THE ITEMS IN THE GAME INCLUDE WEAPONS, ARMOR, CONSUMABLES, TRINKETS, AND RARE RELICS. SOME ITEMS DIRECTLY BOOST ATTACK OR DEFENSE, WHILE OTHERS CAN HEAL HP OR APPLY SPECIAL PASSIVE EFFECTS. THE RARE RELICS ARE ESPECIALLY IMPORTANT BECAUSE THEY ARE POWERFUL AND CAN CHANGE THE WAY THE PLAYER FIGHTS.

THERE IS ALSO A SKILL SYSTEM WHERE THE PLAYER CAN LEARN PASSIVE SKILLS LIKE IRON WILL, RESILIENCE, BATTLE TRANCE, AND OTHERS. THESE SKILLS CAN CHANGE THE GAME SIGNIFICANTLY BY REDUCING DAMAGE, HEALING OVER TIME, IMPROVING ATTACK, OR INCREASING DEFENSE.

THE GAME ALSO HAS A BATTLE LOG TO SHOW WHAT IS HAPPENING DURING THE GAME. IT RECORDS MESSAGES LIKE ATTACKS, DAMAGE DEALT, SKILL TRIGGERS, SPELL EFFECTS, ITEM USE, AND VICTORY NOTIFICATIONS. THIS MAKES THE GAME EASIER TO FOLLOW AND IMPROVES USER EXPERIENCE.

ONE OF THE MOST VISUALLY INTERESTING FEATURES OF THE GAME IS THE USE OF CANVAS DRAWING FOR SPRITES. EACH ENEMY IS DRAWN USING SHAPES LIKE OVALS, RECTANGLES, AND POLYGONS, MAKING THEM LOOK LIKE DIFFERENT MONSTERS IN THE ARENA. THIS ADDS A LIGHT ARCADE FEEL TO THE GAME AND MAKES COMBAT MORE ENJOYABLE TO WATCH.

THE GAME ALSO HAS A PROGRESSION SYSTEM. AS THE PLAYER MOVES TO HIGHER FLOORS, ENEMIES BECOME STRONGER. THIS CREATES A SENSE OF CHALLENGE AND MAKES THE GAME MORE EXCITING. FINAL BOSS FIGHTS ARE MUCH HARDER AND INCLUDE SPECIAL PASSIVE ABILITIES THAT REQUIRE GOOD STRATEGY.

IN CONCLUSION, THIS PROJECT DEMONSTRATES HOW PYTHON, GUI PROGRAMMING, AND LOGIC-BASED DATA DESIGN CAN WORK TOGETHER TO CREATE A GAME. IT COMBINES USER INTERFACE DEVELOPMENT, DATA MANAGEMENT, TURN-BASED COMBAT, ITEM SYSTEMS, SKILL TREE MECHANICS, AND DUNGEON EXPLORATION IN ONE COMPLETE PROJECT.

WE ARE PROUD OF THIS PROJECT BECAUSE IT SHOWS OUR ABILITY TO BUILD A FUNCTIONAL, INTERACTIVE PROGRAM THAT IS BOTH ENTERTAINING AND TECHNICALLY CHALLENGING. THANK YOU FOR LISTENING.
